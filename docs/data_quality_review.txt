Image geometry
Public dataset notes establish RGB-aligned depth but do not unambiguously identify
whether the Azure RGB exports are raw-distorted or rectified. Available utility
scripts reference RealSense cameras and cannot resolve that Azure convention.
Projection comparisons favor applying distortion in typical residuals, but they
are hypotheses with occlusion/timing/depth limitations, not independent confirmation.
configs/image_geometry.json disables fusion. require_projection_policy rejects
disabled, unknown, evidence-free or calibration-mismatched geometry contracts.
Confirmation requires the Azure export source or matching camera_info metadata.
Publisher source: https://github.com/Viky397/TorWICDataset#torwic-slam-faq

Extra annotation schema and provenance
All 237 pairs / 79 groups passed metadata-based instance-to-semantic validation.
158 source images are 848x480 and 79 are 1280x720; all have unknown split provenance.
215 pairs require semantic remapping. Even instance values below 16 can belong
to a different class. Each raw_labels_2d.json labelMapping is therefore used to
translate instance IDs into the fixed semantic taxonomy; originals are unchanged.
Unmapped IDs and conflicting category mappings are rejected. This normalizer is
for extra annotated masks, not the already semantic trajectory masks.
No duplicate source pixel identities occurred within the extra set.
A limited lookup against cached June left-RGB file hashes found no exact-byte
matches; re-encoded, cropped, right-camera or held-out overlap is not ruled out.
All annotations remain quarantined: zero were used or admitted for training.
The initial direct-class-ID report is retained as superseded evidence; its schema
interpretation was corrected before any annotations were used.

Bounds use training percentiles only and are data-envelope filters, not physical calibration.
Noise, blur, LiDAR thinning and geometric warps remain disabled in this policy.

Retained measured depths unchanged; unknown depths not invented; clean RGB/depth/
semantic references byte-identical. Exported input PNGs round-trip exactly.
Metadata includes source paths/hashes, calibration/code/policy hashes, timestamp,
pose, side, donor ID, seed, parameters and rejection reasons. Labels remain
measured sensor depth and provided semantic predictions, not new ground truth.
Only training sensors were opened for augmentation. No validation/test tuning.
Visual appearance and envelope acceptance do not certify physical sensor realism.
